# USGS Denver Fall 2026

Materials, examples, and resources from the Fall 2026 MATLAB workshop delivered to researchers and developers at the U.S. Geological Survey (USGS) Denver Federal Center.

## Overview
Topics include:

- Scientific data analysis in MATLAB
- Geospatial and mapping workflows
- New Mapping Toolbox capabilities
- MATLAB and Python interoperability
- Deployment of applications and APIs
- Agentic AI with MATLAB and Simulink
- Reproducible and validated scientific computing workflows

## Repository Contents

### Mapping and Geospatial Examples
Examples demonstrating:

- GeoTIFF and raster data visualization
- Shapefile and vector data workflows
- CRS management
- 2D and 3D geographic visualizations
- Environmental and earth science datasets

### Python Integration
Examples showing how to:

- Call Python from MATLAB
- Call MATLAB from Python
- Exchange data between MATLAB and Python
- Manage Python environments from MATLAB

### Agentic AI
Demonstrations and resources covering:

- MATLAB Agentic Toolkit
- Simulink Agentic Toolkit
- Model Context Protocol (MCP)
- AI-assisted coding workflows
- Tool-driven agents for engineering and scientific applications

Recommended software:
- MATLAB R2026a or newer
- Mapping Toolbox
- Python (optional for interoperability examples)
- MATLAB Agentic Toolkit (optional)
- Simulink Agentic Toolkit (optional)
